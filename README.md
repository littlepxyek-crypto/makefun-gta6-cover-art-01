Vice Cover Studio turns up to four of your own photos into multi-panel GTA-poster-style cover art: three panel layouts, per-panel crop and zoom, an adjustable Vice City sunset/neon grade, and an Anton display caption. It exports finished PNG covers at 1080 x 1080, 1080 x 1350 and 1920 x 1080, and runs fully offline in the browser with no build step.

## Run it

```sh
node serve.ts
```
